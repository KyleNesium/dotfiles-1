# Genre Reference Index

Comprehensive per-genre production guides — history, characteristics, reference artists/tracks, production DNA, tempo/key recommendations, and library-pack hints.

## How to use

When the user references a genre directly ("make a melodic techno track", "this should sound more like organic house"), **read the relevant genre file** before suggesting tempo, key, instrument choices, or arrangement. Each doc ends with a "Production DNA — translate to decisions" section with concrete defaults.

When the user gives a reference artist or track, cross-reference against the artist tables in each genre doc to identify which genre cluster they're working in.

When the user wants to write outside their main lane, cite the relevant genre doc rather than improvising.

## Quick reference — picking a genre by intent

| User says | Reach for |
|--|--|
| "make me a track" | progressive-house (default to user's spine) |
| "darker / more emotional" | melodic-techno |
| "with vocals / more accessible" | melodic-house |
| "warm / sunset / chill" | organic-house |
| "harder / more driving" | tech-house → afro-tech → hard-groove (escalating) |
| "tribal / percussion-heavy" | tribal-techno or afro-house |
| "more atmospheric / dub" | dub-techno |
| "ethnic / world flavors" | desert-tech or organic-house |
| "old-school / analog" | indie-dance or classic house |
| "fast / hypnotic" | progressive-psy-trance |
